# Learning notes

This is the learning journal for building Vitae. One note per milestone. The point is not to
restate the code, it is to capture understanding: what a concept is, why we chose it, what
confused you, and the mental model that finally made it click.

Good notes make this a portfolio, not just a repo. A reviewer reading these should see how you
think, not only what you shipped.

## Convention

- File name: `NN-short-topic.md`, numbered to match the milestone (00 for M0, 01 for M1, ...).
- Write in your own words. If you only copied it, you did not learn it.
- When something surprised you or you had to look it up, write that down. Those are the real gaps.
- Link decisions to their ADR in `docs/adr/` when relevant.

## Suggested shape for each note

- What I was trying to do
- The core idea, in one paragraph, from first principles
- How it maps to something I already know (often TypeScript or Node)
- What tripped me up, and how I resolved it
- One thing I could not have guessed and want to remember
